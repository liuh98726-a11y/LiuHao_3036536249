本仓库用于 Fama 和 French（1993）三因子项目的论文复现。当前仅建立了老师模板要求的项目结构；数据、因子构建代码、结果和最终报告尚未完成。

## 计划中的复现范围

- 以原始股票、财务、链接及无风险利率数据构建 2000—2025 年月度 MKT−RF、SMB 和 HML。
- 生成主要汇总统计、累计收益图，并与 Kenneth French 数据库的相应因子比较。
- 完成一个回答明确经济问题的独立扩展，并在 `report.pdf` 中解释结果与局限。

以上是目前根据课程材料整理的工作范围；具体数据口径和扩展问题将在研究设计确定后写入本文件。

## 项目结构

| 路径 | 用途 |
| --- | --- |
| `data/raw/` | 放置原始输入数据；受限数据只在本地保存，不提交到 Git |
| `data/processed/` | 放置分析使用的处理后数据；提交前检查分享许可 |
| `code/run_all.py` | 最终的一键运行入口；目前是明确报错的占位脚本 |
| `outputs/tables/` | 代码生成的主要表格 |
| `outputs/figures/` | 代码生成的主要图形 |
| `skills/SKILL.md` | 后续复用图表生成流程的项目说明 |
| `AI_USE_DISCLOSURE.md` | AI 使用与人工核验记录 |
| `report.pdf` | 最终研究报告；完成后添加 |
