# Replication output workflow

This project is currently a scaffold. Do not report results until the required input data and analysis code exist.

Once implemented, run `python code/run_all.py` from the repository root with the documented input files under `data/raw/`. Check that the expected tables in `outputs/tables/` and figures in `outputs/figures/` are regenerated, and record any missing inputs or failed checks. Keep the exact input requirements and output list aligned with `README.md` as the analysis develops.
